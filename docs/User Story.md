### US01 – Gestão de Usuários
Como usuário, quero criar e acessar minha conta para utilizar a plataforma. Esta história irá criar a interface de login, o backend para processar a ação de login e o armazenamento de usuários em banco. 

### US02 - Gestão de Habilidades 
Como usuário, quero cadastrar as habilidades que posso ensinar e as que desejo aprender, para que a plataforma encontre pessoas compatíveis. Descrição: Criar um formulário onde o usuário informe as habilidades que pode ensinar e as habilidades que deseja aprender. Critérios de Aceitação: Permitir cadastrar habilidades para ensinar e aprender. Salvar as informações no perfil do usuário. Permitir editar e excluir habilidades. Utilizar essas informações para gerar recomendações. 

### US03 - Match Inteligente
Como usuário, quero encontrar pessoas compatíveis para troca de conhecimentos. Esta história irá criar o sistema de recomendação e compatibilidade entre usuários, exibindo perfis com habilidades relacionadas aos interesses cadastrados, além da integração com o backend e banco de dados para processar e armazenar os matches realizados  

### US04 - Comunicação 
Como usuário, quero conversar com outros usuários em tempo real. Esta história irá criar a interface de chat em tempo real, permitindo troca de mensagens entre usuários, além da integração com o backend e banco de dados para envio, recebimento e armazenamento das conversas. 

### US05 - Agendamento 
Como usuário, quero marcar sessões de aprendizado com outros usuários. Esta história irá criar a interface de agendamento de sessões, permitindo selecionar data, horário e usuário participante, além da integração com o backend e banco de dados para gerenciamento dos agendamentos.

### US06 - Aulas Online 
Como usuário, quero participar de videochamadas diretamente na plataforma. Esta história irá criar a funcionalidade de videochamadas online, permitindo que usuários participem de sessões de aprendizado em tempo real dentro da plataforma, além da integração com serviços de comunicação e backend para gerenciamento das salas virtuais. 

### US07 - Avaliações 
Como usuário, quero avaliar outros usuários após as sessões. Esta história irá criar a interface de avaliações e feedbacks, permitindo atribuir notas e comentários após as sessões realizadas, além da integração com o backend e banco de dados para armazenamento e consulta das avaliações.

### US08 - Histórico
Como usuário, quero visualizar meu histórico de interações para acompanhar minhas atividades dentro da plataforma. Esta história irá criar a interface de histórico, permitindo ao usuário visualizar suas interações realizadas, como trocas de habilidades, aulas marcadas, solicitações e atividades recentes, além da integração com o Backend e banco de dados para armazenamento e consulta dessas informações.
