# Backend (Express + SQLite)

Arquivos adicionados para rodar um backend mínimo que serve o frontend estático e expõe APIs REST.

Localização do DB: `data/app.db`

Principais arquivos criados:
- `server.js` — servidor Express
- `package.json` — dependências e scripts
- `db/init.sql` e `db/db.js` — inicialização do SQLite
- `routes/*.js` — rotas `auth`, `users`, `agenda`

Ver `README.md` na raiz para instruções de execução.
