# SkillEx – Plataforma Web de Troca de Habilidades

> Conectando pessoas que querem ensinar e aprender por meio da troca colaborativa de conhecimentos.

---

## Sobre o Projeto

O **SkillEx** é uma plataforma web que conecta pessoas interessadas em compartilhar conhecimentos e desenvolver novas habilidades. Cada usuário pode cadastrar aquilo que sabe ensinar e o que deseja aprender.

Com base nessas informações, o sistema identifica perfis compatíveis e promove a troca de conhecimentos de forma colaborativa, permitindo que os usuários se conectem, conversem, agendem aulas e realizem videochamadas diretamente pela plataforma.

---

## Objetivo

Desenvolver uma aplicação web que permita:

- Cadastro e autenticação de usuários;
- Registro de habilidades que o usuário pode ensinar;
- Registro de habilidades que deseja aprender;
- Correspondência automática entre usuários compatíveis;
- Comunicação por chat em tempo real;
- Agendamento de sessões de aprendizado;
- Aulas online com videochamadas integradas;
- Histórico de interações;
- Sistema de avaliações e comentários.

- Cadastro de habilidades a aprender
- Organização por categorias

### Match Inteligente
- Correspondência entre usuários com interesses complementares
- Recomendações automáticas

### Comunicação
- Chat em tempo real
- Notificações

### Agendamento
- Marcação de sessões de aprendizado
- Controle de horários

### Aulas Online
- Videochamadas integradas à plataforma

### Avaliações
- Sistema de notas e comentários
- Histórico de trocas realizadas
